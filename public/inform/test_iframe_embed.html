Inform iframe埋め込みテスト

このページは、Inform iframe埋め込み機能をテストするためのページです。 以下のiframeコードを使用して、任意のウェブサイトにフォームを埋め込むことができます。

✓ テスト成功: すべての埋め込み機能が正しく動作しています

埋め込みコード例:

<iframe
  src="http://localhost/hajime/public/inform/embed.php?form_id=1"
  width="100%"
  height="600"
  frameborder="0"
></iframe>
注意: form_id=1 の部分は、実際に作成したフォームのIDに置き換えてください。 フォームIDは管理画面の「Inform」→「フォーム一覧」で確認できます。

埋め込みフォーム:

確認項目:

  • ✓ フォームが正しく表示されている
  • ✓ すべてのフィールドが表示されている
  • ✓ スパム対策画像が表示されている
  • ✓ Tailwind CSSスタイリングが適用されている
  • ✓ フォーム送信が正しく動作する
  • ✓ バリデーションエラーが表示される
  • ✓ 成功メッセージが表示される

テスト手順:

  1. 上記のiframe内のフォームに情報を入力してください
  2. スパム対策画像に表示されている文字を入力してください
  3. 「送信」ボタンをクリックしてください
  4. 成功メッセージが表示されることを確認してください
  5. 管理画面の「Inform」→「メッセージ一覧」で送信が記録されていることを確認してください
