# メッセージ管理ページ

## 概要

このディレクトリには、Inform お問い合わせフォームシステムのメッセージ管理機能が含まれています。

## ファイル

### messages.php

メッセージ一覧ページ。受信したすべてのフォーム送信を表示・管理します。

**機能:**

- すべての送信を一覧表示
- フォーム名、送信日時、ステータス、IPアドレスを表示
- フィルタリング機能（フォーム、ステータス、日付範囲）
- ステータス変更（ドロップダウンから選択）
- 削除機能
- 詳細ページへのリンク

**要件:** 7.1, 7.2, 7.4, 7.5, 7.6

### message-detail.php

メッセージ詳細ページ。個別の送信内容を表示します。

**機能:**

- 送信情報の表示（フォーム名、送信日時、IPアドレス、ユーザーエージェント、ステータス）
- すべてのフィールド値を表示
- ステータス変更フォーム
- メッセージ一覧へ戻るリンク

**要件:** 7.3, 7.4

## 使用方法

### メッセージ一覧にアクセス

1. Hajime CMS管理画面にログイン
2. Inform → フォーム一覧 → メッセージ管理ボタンをクリック
3. または直接 `/admin/inform/messages.php` にアクセス

### フィルタリング

1. フィルタセクションで条件を選択
   - フォーム: 特定のフォームの送信のみ表示
   - ステータス: 新規、対応中、解決済みで絞り込み
   - 開始日/終了日: 日付範囲で絞り込み
2. 「フィルタを適用」ボタンをクリック
3. 「クリア」ボタンでフィルタをリセット

### ステータス変更

**方法1: 一覧ページから**

1. 各送信の「ステータス変更」ドロップダウンを選択
2. 新しいステータスを選択すると確認ダイアログが表示される
3. OKをクリックして更新

**方法2: 詳細ページから**

1. 「詳細」リンクをクリック
2. ステータス変更セクションで新しいステータスを選択
3. 「更新」ボタンをクリック

### 削除

1. 一覧ページで「削除」ボタンをクリック
2. 確認ダイアログでOKをクリック
3. 送信がデータベースから削除される

## セキュリティ

- **認証**: Hajime CMS認証を使用（未認証アクセスはログインページにリダイレクト）
- **XSS対策**: すべてのユーザー入力を `htmlspecialchars()` でエスケープ
- **SQLインジェクション対策**: プリペアドステートメントを使用
